# Shitposter 💩

**Shitposter** is your one-stop destination for coordinated, text-only chaos. Designed for high-frequency, high-impact content creation, it's the ultimate tool for monitoring growth and maintaining a chaotic feed.

## 🚀 Features

- **Text-Only Experience**: Pure content, no distractions.
- **AI Assistant (Borg)**: Integrated AI logic to help you navigate and master the feed.
- **Secure Authentication**: Robust phone-number based login system.
- **Premium UI/UX**: Modern Material 3 design with custom iconography and edge-to-edge layouts.
- **Monetization Focused**: Tools to track growth and turn your posts into income.

## 🛠️ Technology Stack

- **Platform**: Android (Native)
- **Language**: Java
- **UI Components**: Material Components for Android (Material 3)
- **Architecture**: ViewBinding with professional fragment-based navigation.
- **Build System**: Gradle with Version Catalog (`libs.versions.toml`).

## 📲 Getting Started

### Prerequisites

- Android Studio Koala (or newer)
- Android SDK (Targeting API 36)
- Java 11

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/shitposter.git
   ```

2. **Open in Android Studio**
   - File > Open... > Select the project directory.

3. **Build & Run**
   - Sync Gradle files.
   - Run on an emulator or physical device.

## 📂 Project Structure

- `app/src/main/java`: Core application logic (Activities, Fragments, Models).
- `app/src/main/res/layout`: Modern XML layouts with ConstraintLayout.
- `app/src/main/res/drawable`: Custom vector iconography (Home, Borg, etc.).
